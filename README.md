# Хирургический фотоархив

Локальное Android-приложение для систематизации клинических фотографий по пациентам.

## Возможности

- Android 9+ (`minSdk 28`).
- Каталог пациентов с поиском по ФИО и номеру карты.
- Карточка пациента: диагноз/клинический случай и краткая заметка.
- Три раздела фотографий: **До**, **Операция**, **После**.
- Добавление снимков через системную камеру и множественный импорт из галереи.
- Краткое описание для каждого снимка.
- Удаление пациентов и фотографий.
- Фото хранятся в app-private `filesDir/clinical_images`; приложение не запрашивает доступ ко всему хранилищу и не имеет INTERNET permission.
- `allowBackup=false` и `FLAG_SECURE` для снижения риска утечки медицинских данных.
- Jetpack Compose Material 3 Adaptive `NavigableListDetailPaneScaffold`: одна панель на узком телефоне, list-detail на планшете/раскрытом Fold, с учётом конфигурации окна и складных устройств.

## Сборка

Требуется Android Studio с JDK 17 и Android SDK 37.

1. Откройте папку `ClinicalPhotoArchive` в Android Studio.
2. Дождитесь Gradle Sync.
3. Установите SDK 37, если Android Studio предложит это сделать.
4. Запустите на устройстве/эмуляторе Android 9+.

Проект использует AGP 9.3.1 и Gradle 9.5.0.

## Медицинская безопасность

Это исходная первая версия для личной локальной базы. Перед использованием в клинике проверьте требования вашей организации и применимого законодательства к персональным медицинским данным. Для следующей версии целесообразно добавить биометрический/PIN-доступ, шифрование экспортных резервных копий и аудит действий.
