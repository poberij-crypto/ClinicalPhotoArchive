# ClinicalPhotoArchive Migrator

Одноразовая Android-утилита для извлечения данных из старых debug-сборок
`com.clinicalphotoarchive`.

## Принципы безопасности

- не содержит INTERNET permission;
- не отправляет клинические данные во внешние сервисы;
- не изменяет и не удаляет данные старого приложения;
- перед копированием выполняет только `am force-stop` старого приложения;
- читает закрытые данные старой debug-сборки через `run-as`;
- Shizuku используется только как локальный shell/ADB transport.

## Формат архива

Создаётся TAR-файл:

- `databases/` — база Room и возможные WAL/SHM-файлы;
- `files/clinical_images/` — клинические изображения.

До успешного импорта и проверки архива старую debug-версию удалять нельзя.

## Ограничения

`run-as` работает только если установленная старая версия действительно debuggable.
На Android 11+ Shizuku можно запустить на устройстве через Wireless debugging.
На Android 9–10 первоначальный запуск Shizuku без root требует ADB с компьютера.

## Исправления 1.0.1

- Исправлена проверка данных: `OK|16|36864` формируется в Kotlin, а не
  выполняется как shell-конвейер. Проверка и TAR используют прямые `run-as`
  вызовы без `sh -c`.
- Отсутствующая папка фотографий допустима; ошибка доступа останавливает перенос.
- Ошибка остановки старого приложения больше не игнорируется. Проверка повторяется
  после остановки; в TAR по-прежнему входит вся папка databases, включая WAL/SHM.
- Чтение stdout/stderr выполняется параллельно с ограничением времени ожидания.
- Версия Shizuku UserService повышена, чтобы обновление использовало новый код.
- Проверки: `gradle :migrator:testDebugUnitTest :migrator:assembleRelease`.

Проверка на физическом устройстве с Shizuku остаётся необходимой. Успешное
завершение TAR не означает проверки логической целостности SQLite или импорта.
